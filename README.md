## Directory Architecture

Every experiment directory adheres to an identical, standardized folder structure:

```text
Experiment_[NN]/
├── MATLAB/                 # Verified native MATLAB (.m) scripts
├── Python/                 # PEP-8 compliant Python 3.14 (.py) implementations
├── Data/                   # Clinical datasets (DICOM, TIFF, PNG, NIfTI)
├── Outputs/                # High-resolution generated visual and tabular outputs
│   ├── MATLAB/             # Figures, plots, and CSV tables from MATLAB
│   └── Python/             # Figures, plots, and CSV tables from Python
├── Figures/                # Multi-panel composite figures, QR code, and execution screenshots
├── Report/                 # Official deliverables
│   ├── Experiment_[NN]_Report.docx   # Fully formatted Word document
│   └── Experiment_[NN]_Report.pdf    # Print-ready compiled PDF (8–12 pages)
├── test_experiment_[NN].py # Automated 9-tier test suite
└── build_report_optimized.py # Report automation builder
```

## Verification & Execution

### Prerequisites
- **MATLAB:** R2026a (or R2020b+) with Image Processing Toolbox.
- **Python:** 3.10+ (tested on Python 3.14.4).
- **Python Dependencies:** `numpy`, `scipy`, `scikit-image`, `opencv-python`, `pydicom`, `matplotlib`, `pillow`, `python-docx`, `pypdf`, `qrcode`.

### Running Automated Test Suites
To run tests for any experiment:
```powershell
cd Experiment_01
python test_experiment_01.py
```
